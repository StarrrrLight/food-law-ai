# Food Law AI | 무료 식품법규 근거검색 및 실무 검토 데스크 v0.2

이 프로젝트는 **유료 결제, AI API, 계정 로그인 없이** 웹 브라우저에서 동작하는 정적 웹앱입니다.

## v0.2 개선 사항
- 답변을 먼저 표시하는 화면. 냉장육 일시 표면 경화, 임의 냉동전환, 냉동육 절단 해동 등 특정 검증 사례에 한하여 미리 정리한 조건부 판단을 제공합니다.
- 판단 카드에서 법령 별표(2026.08.11 시행판) 및 식약처 공식 Q번호 원문을 직접 연결합니다.
- 대표님 보고용 문구를 바로 복사할 수 있습니다.
- 일반 질문은 검증된 판단이 없음을 명확히 표시하고 FAQ 원문 발췌만 제공합니다.

## 포함 기능
- 2025 식약처 「자주하는 질문집」 **872문항**의 질문 및 답변 본문 검색
- 영업·표시·축산물 등 분야별 FAQ 필터, 질문별 상세 보기와 인쇄 페이지 연결
- 같은 자료에서 인용된 법령과 국가법령정보센터 공식 원문 바로가기
- 법률·시행령·시행규칙·고시 16종 법령 서재
- 대표 질의 예시(냉장육 일시 표면 경화와 냉동전환)를 비교 검색
- 검토 초안 복사, 검색 이력, FAQ 즐겨찾기, 개인 메모, 기록 JSON 내보내기
- 내 법령 TXT 자료 가져오기 및 브라우저 내부 IndexedDB 저장
- 업로드된 공식 FAQ PDF 전체 710페이지 파일을 로컬 뷰어로 열기

## 중요한 제한
- **생성형 AI 답변이 아닙니다.** 유료/호스팅 AI API를 사용하지 않으며, 일부 검증된 사례만 미리 작성한 요약으로 제시하고 나머지는 관련 FAQ를 검색합니다.
- 2025 식약처 민원인 안내서는 법적 효력을 갖지 않으며 이후 법령 개정에 따라 달라질 수 있습니다.
- 법령 서재의 법률·고시 **현행 원문은 공식 사이트로 연결**합니다. 별도 승인 없이 법제처 API를 무단 호출하거나 확인하지 않습니다.
- 일부 사례에서는 특정 별표 판본으로 직접 연결하지만, 전체 법령 원문과 모든 조문을 자동 검증하거나 갱신하지 않습니다. 해당 별표의 시행일과 개정 여부를 재확인해야 합니다.
- 개인 저장 정보는 서버로 보내지 않고 **브라우저 로컬 저장소**에 보관합니다. 브라우저 데이터 삭제 시 사라지므로 JSON 백업을 권장합니다.
- **회사 기밀·개인정보를 공개 GitHub 저장소에 업로드하지 마세요.** 공개될 소스에는 공식 공개자료만 포함해야 합니다.

## 설치 없이 내 컴퓨터에서 바로 실행
1. ZIP을 다운로드한 뒤 **압축을 풉니다**.
2. 압축을 푼 폴더 안의 `index.html` 파일을 **더블클릭**하면 브라우저에서 열립니다.
3. 모든 FAQ 및 원본 PDF는 ZIP에 포함되어 있으므로, 공식 법령 원문 링크를 제외하면 인터넷 없이도 검색 가능합니다.
4. 로컬 파일에서 브라우저 저장소가 제한된다면 GitHub Pages 또는 무료 정적 호스팅으로 열어 주세요.

## 가장 쉬운 무료 온라인 배포: Netlify Drop
1. https://app.netlify.com/drop 에 접속합니다.
2. **ZIP 자체를 끌어다 놓으면** 무료 사이트가 생성됩니다. 생성된 URL을 기록하세요.
3. 추후 수정본을 재배포하려면 무료 계정으로 프로젝트를 소유하면 됩니다.
4. Netlify의 Free 플랜은 월간 무료 크레딧에 상한이 있으며, 초과하면 자동 과금이 아니라 무료 사용이 제한됩니다.

## 100% 무료 공개하기: GitHub Pages
1. GitHub 로그인 후 **New repository**를 눌러 `food-law-ai`라는 **Public** 저장소 생성
2. 이 ZIP을 풀고 내부 파일/폴더 전부를 저장소 최상단에 업로드하여 `main` 브랜치에 커밋 (`index.html`, `styles.css`, `app.js`, `assets/` 등)
3. **Settings → Pages → Build and deployment → Deploy from a branch** 선택
4. **Branch: `main`, Folder: `/ (root)`** 로 설정하고 Save
5. GitHub의 Pages 화면에서 생성된 주소를 확인하여 접속

비공개 코드 또는 회사 내부 문서는 공개 저장소에 올리지 말고, 개인용 사용으로 제한하세요. GitHub Pages의 무료 저장소는 Public이어야 합니다.

## 내 컴퓨터에서 테스트
로컬 Python이 있으면 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.
